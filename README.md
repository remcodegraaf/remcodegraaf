## How I build

**The agent thinks, the system enforces.** Guards live in the path, not beside it: pre-commit hooks, breakers, CI gates and database constraints decide what ships. The agent reasons inside that boundary.

- **Two labs, not one.** Claude Code builds, OpenAI Codex reviews as an independent second lab. Every finding is a hypothesis until it is verified against file and line.
- **Armed first, audited after.** Autonomous loops act, a daily two-model audit re-examines every action within 24 hours. Rollback over pre-approval.
- **A gate only counts once you have seen it fail.** Every guard is proven red before it is trusted green.
- **Enumerate by grep, not by reasoning.** Plans go stale the moment code moves.

All of this runs on private repositories. The contribution graph is the public trace: more than 11,000 commits in the past year across two production platforms.
